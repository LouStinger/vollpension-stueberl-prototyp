# Vollpension Investorenstüberl – Prototyp

Klickbarer Prototyp: interaktive Microsite für Investor:innen plus Admin-Bereich (Demo).

- `index.html` – Stüberl, Admin-Bereich über das Burger-Menü
- `admin.html` – Admin-Bereich allein

Alle Investoren, Zahlen und Aktivitäten sind erfunden. Es werden keine Daten an einen Server gesendet; die Demo speichert nur lokal im Browser.
